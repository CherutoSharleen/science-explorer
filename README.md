# Science Explorer

An original Grade 8 Integrated Science learning site with seven topics, 35 visual
missions, 700 practice questions, 70 revision cards and seven downloadable revision
guides.

**Open the site:** https://CherutoSharleen.github.io/science-explorer/

## Scores and privacy

Designed for one learner, with separate progress saved per topic in the current
browser's `localStorage`. Multiple-choice answers are checked automatically;
short answers are self-assessed. The site can export progress statuses.

Scores are not uploaded to GitHub or stored in this repository. There are no
accounts, backend, analytics or cross-device sync. Clearing browser/site data can
erase progress; use the progress export to keep a separate record. Other people
using the same browser profile can access the same progress.

Optional external videos and source links require internet access and are subject
to the external providers' privacy policies.

## Hosting and offline use

GitHub Pages serves `main` from the repository root, with no build command or
server required. Keep all HTML, JSON, PDF and content-hashed `science-*.css` and
`science-*.js` files together; `.nojekyll` enables plain static-file publishing.

To use the site offline, download the repository, unzip it and open `index.html`.
Visiting the hosted site does not install an offline app. Progress storage for
local files varies between browsers.

## Teaching resources and sources

The seven revision PDFs are original, distributable teaching resources. The KICD
curriculum is linked externally only: its source PDF is not hosted or included.
Do not add private progress exports, source curriculum uploads, attachments or
development artifacts to this public repository.

This independent educational prototype is not KICD-endorsed. Teacher review is
required before classroom use; the site does not replace supervised practical
work or formal assessment.
